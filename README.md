# ConnexR News Ideation Studio
Browser-hosted app for latest-news discovery, blog topic ideation, keyword suggestions, SEO/GEO/AEO angles, and ready-to-copy prompts. It does not generate articles.

No OpenAI API key or paid AI API required. No website/CMS integration.
Deploy by uploading app.py, requirements.txt and README.md to GitHub, then deploy app.py from Streamlit Community Cloud: https://share.streamlit.io/

News uses public Google News RSS. Keyword ideas are framework-based suggestions, not verified search-volume/difficulty metrics. Export CSV regularly; cloud local storage may not persist across restarts.
